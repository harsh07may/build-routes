Python to FastAPI

    From Python basics to shipping APIs.

    The shortest path from knowing Python to building and running a URL shortener with FastAPI, Postgres and Redis on your own. Each stop is one idea with one working example. Mark stops as done to track your progress on this device.

      Prerequisites: Python essentials

      The Python-specific behaviour and idioms the rest of this guide assumes. Skim what you know, stop on what surprises you.

      Names, mutability and truthiness

      Variables are names pointing at objects, not boxes holding values. Assignment never copies. Lists, dicts and sets are mutable; ints, strings and tuples are not.

b = a                  # same list, two names
b.append(3)
print(a)               # [1, 2, 3]
c = a.copy()           # shallow copy; copy.deepcopy() for nested structures

x == y                 # equal values
x is None              # same object; use `is` only for None, True, False

# falsy: None, False, 0, 0.0, "", [], {}, set(), ()   everything else is truthy
if not items:
    print("empty")
name = user_input or "anonymous"     # first truthy value

      Scope and closures

      Name lookup goes Local, Enclosing function, Global, Built-in. An inner function that remembers variables from its enclosing function is a closure; decorators are built on this.

      def make_counter():
    count = 0
    def increment():
        nonlocal count              # without this, count += 1 raises UnboundLocalError
        count += 1
        return count
    return increment

next_id = make_counter()
next_id(), next_id()                # (1, 2)  count lives on between calls

      A module is a .py file; a package is a folder of modules with an __init__.py. A module's top-level code runs once, on first import, so a module-level object behaves like a singleton. That's how a shared settings object works later.

      Function design

      Three habits for functions other code depends on: make optional arguments keyword-only, use None as the default for anything mutable, and pass functions around as values when behaviour varies.

      def shorten(url: str, *, code: str | None = None, tags: list[str] | None = None) -> str:
    tags = tags or []            # never write tags: list = [] as a default
    ...

shorten("https://x.dev", code="xdev")   # ok
shorten("https://x.dev", "xdev")        # TypeError: code is keyword-only (after *)

transforms = {"upper": str.upper, "strip": str.strip}   # functions are values
transforms["upper"]("hi")               # 'HI'

      Why the default rule: a default value is evaluated once, when the function is defined, so a mutable default list is shared across every call.

      Classes and dataclasses

      For plain internal data, @dataclass writes __init__, __repr__ and __eq__ for you.

      from dataclasses import dataclass, field
from datetime import datetime, timezone

@dataclass
class Link:
    code: str
    target: str
    clicks: int = 0
    created_at: datetime = field(default_factory=lambda: datetime.now(timezone.utc))

    def hit(self) -> None:
        self.clicks += 1

    def is_popular(self) -> bool:
        return self.clicks > 100

    @classmethod                       # alternative constructor
    def from_dict(cls, data: dict) -> "Link":
        return cls(**data)

      Exceptions

      Define domain errors once, raise them deep in your logic, and translate them to HTTP responses in one place (see Responses and errors in the FastAPI part).

      class LinkError(Exception):
    """Base class for all link errors."""

class LinkNotFound(LinkError): ...
class CodeTaken(LinkError): ...

def resolve(store: dict[str, str], code: str) -> str:
    try:
        return store[code]
    except KeyError as e:
        raise LinkNotFound(code) from e     # keeps the original cause in the traceback

try:
    resolve({}, "nope")
except LinkNotFound as e:
    print(f"missing: {e}")
else:
    print("found")          # runs only if nothing was raised
finally:
    print("always runs")    # cleanup

      Decorators

      A decorator is a function that takes a function and returns a replacement. @timed above def slow() means slow = timed(slow).

      import functools
import time

def timed(fn):
    @functools.wraps(fn)                 # keep fn's name and docstring
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        try:
            return fn(*args, **kwargs)
        finally:
            print(f"{fn.__name__} took {time.perf_counter() - start:.4f}s")
    return wrapper

@timed
def slow() -> None:
    time.sleep(0.2)

slow()     # slow took 0.2001s

      A decorator with arguments, like @app.get("/health"), is a function that returns a decorator. FastAPI's version registers your function as a route and returns it unchanged.

      Generators and yield

      A function containing yield produces values lazily, one at a time. Code after the yield runs when the generator is resumed or closed: exactly how FastAPI dependencies do setup and teardown.

def session_scope():                     # the shape of a FastAPI yield dependency
    print("setup")

    finally:

      The FastAPI toolkit

      FastAPI is mostly type hints, Pydantic and async put together. Learn these three on their own and FastAPI stops feeling like magic.

      Type hints

      Python does not enforce hints at runtime. Pydantic and FastAPI read them to validate input, convert types and generate API docs. A type checker (Pyright, mypy, or your editor's built-in one) catches mistakes before you run anything, so turn it on.

      from collections.abc import Callable
from typing import Annotated, Literal

def top(counts: dict[str, int], n: int = 5) -> list[str]: ...   # built-in generics
def find(code: str) -> str | None: ...                          # Optional[str] in older code

Method = Literal["GET", "POST", "DELETE"]          # only these exact values
Handler = Callable[[str], str]                     # takes a str, returns a str
Code = Annotated[str, "any metadata"]              # a str, plus metadata FastAPI can read

      Why Annotated matters: FastAPI uses it to attach extra meaning to a type: Annotated[int, Query(ge=1)] is "an int, read from the query string, at least 1".

      Pydantic v2

      A Pydantic model validates and converts data on the way in, and serializes it on the way out. In FastAPI, request bodies and responses are Pydantic models.

      from pydantic import BaseModel, ConfigDict, Field, HttpUrl, ValidationError, field_validator

RESERVED = {"docs", "redoc", "links", "health"}

class LinkCreate(BaseModel):                       # what the client sends
    url: HttpUrl
    code: str | None = Field(default=None, min_length=4, max_length=16,
                             pattern=r"^[A-Za-z0-9_-]+$")

    @field_validator("code")
    @classmethod
    def not_reserved(cls, v: str | None) -> str | None:
        if v in RESERVED:
            raise ValueError("this code is reserved")
        return v

class LinkOut(BaseModel):                          # what the API returns
    model_config = ConfigDict(from_attributes=True)    # allow building from ORM objects
    code: str
    target_url: str
    clicks: int = 0

data = LinkCreate.model_validate({"url": "https://example.com"})
data.model_dump()          # -> dict
data.model_dump_json()     # -> JSON string

try:
    LinkCreate(url="not a url")
except ValidationError as e:
    print(e.errors())      # FastAPI turns this into a 422 response automatically

      Watch out: HttpUrl is a URL object, not a str. Convert with str(data.url) before storing it. Also note that Pydantic's default (lax) mode converts compatible values, such as "5" into 5 for an int field.

      async and await

      Async lets one thread juggle many tasks that are waiting on I/O (network, database, Redis). While one request waits for Postgres, the event loop serves others. It is concurrency, not parallelism.

      import asyncio
import time

async def fake_io(n: int) -> int:          # calling it returns a coroutine; nothing runs yet
    await asyncio.sleep(1)                 # yields control to the event loop while waiting
    return n

async def main() -> None:
    start = time.perf_counter()
    results = await asyncio.gather(fake_io(1), fake_io(2), fake_io(3))
    print(results, f"{time.perf_counter() - start:.1f}s")    # [1, 2, 3] 1.0s, not 3.0s

asyncio.run(main())                        # starts the loop (FastAPI does this for you)

      A real example with an async HTTP client (httpx ships with fastapi[standard]):

      import httpx

async def check_alive(urls: list[str]) -> dict[str, int]:
    async with httpx.AsyncClient(timeout=5, follow_redirects=True) as client:
        responses = await asyncio.gather(*(client.head(u) for u in urls))
    return {u: r.status_code for u, r in zip(urls, responses)}

      The rules that matter in FastAPI:

      • Inside async def, never call blocking code: time.sleep, requests, synchronous database drivers. It stalls every request on the server. Use async libraries, or wrap unavoidable blocking calls with await asyncio.to_thread(fn, arg).
      • FastAPI runs plain def endpoints in a thread pool, so synchronous libraries are safe there. Choose per endpoint.
      • Async does not speed up CPU-heavy work. Offload that to a separate process or a job queue.

      Responses and errors

      The return annotation validates, filters and documents what leaves your API. Fields not in the output model are never sent, which keeps internal columns private. If you return a dict or an ORM object instead of the model itself, declare the model with response_model=LinkOut on the decorator.

      from fastapi import HTTPException, Request, status
from fastapi.responses import JSONResponse, RedirectResponse

store: dict[str, str] = {"abc": "https://example.com"}    # code -> target URL

@app.get("/links/{code}")
async def get_link(code: str) -> LinkOut:
    target = store.get(code)
    if target is None:
        raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="link not found")
    return LinkOut(code=code, target_url=target)

@app.get("/{code}")
async def follow(code: str) -> RedirectResponse:
    target = resolve(store, code)                         # raises LinkNotFound
    return RedirectResponse(target, status_code=302)      # default is 307

@app.exception_handler(LinkNotFound)                       # translate domain errors once
async def on_not_found(request: Request, exc: LinkNotFound) -> JSONResponse:
    return JSONResponse(status_code=404, content={"detail": f"no link '{exc}'"})

      resolve and LinkNotFound are from the Exceptions stop. Raising HTTPException directly is fine in routes; domain exceptions plus a handler keep HTTP details out of your business logic.

      Free validation errors: invalid input never reaches your function. FastAPI returns a 422 with a list of which fields failed and why.

      Dependency injection with Depends

      A dependency is a function FastAPI calls before your endpoint, passing in its result. Use it for database sessions, the current user, API keys, pagination and settings. Dependencies can depend on other dependencies, and each one is called at most once per request.

      from typing import Annotated
from fastapi import Depends, Header, HTTPException

def pagination(skip: int = 0, limit: int = 20) -> tuple[int, int]:
    return skip, min(limit, 100)

async def require_api_key(x_api_key: Annotated[str, Header()]) -> None:
    # reads the "x-api-key" header (underscores become hyphens)
    if x_api_key != settings.api_key:
        raise HTTPException(status_code=401, detail="invalid API key")

Paging = Annotated[tuple[int, int], Depends(pagination)]      # reusable alias

@app.get("/links", dependencies=[Depends(require_api_key)])   # run it, ignore its value
async def list_links(paging: Paging):
    skip, limit = paging
    ...

      A dependency with yield does setup before the yield and cleanup after it. That's the pattern for database sessions in the persistence part. In tests, swap any dependency with app.dependency_overrides[real] = fake.

      Lifespan, middleware and background tasks

      lifespan runs code once at startup (before yield) and once at shutdown (after). Create long-lived clients here, not per request. Middleware wraps every request.

      import time
from contextlib import asynccontextmanager
import redis.asyncio as redis
from fastapi import FastAPI, Request
from app.core.config import settings
from app.db import engine

@asynccontextmanager
async def lifespan(app: FastAPI):
    app.state.redis = redis.from_url(settings.redis_url, decode_responses=True)
    yield
    await app.state.redis.aclose()
    await engine.dispose()

app = FastAPI(lifespan=lifespan)

@app.middleware("http")                                 # runs around every request
async def add_timing(request: Request, call_next):
    start = time.perf_counter()
    response = await call_next(request)
    response.headers["X-Process-Time"] = f"{time.perf_counter() - start:.4f}"
    return response

      Design hints

      • Generating codes: either encode the row's integer id in base62 (short, unique, but guessable and sequential) or draw random characters with the secrets module and retry on collision. Try both and compare.
      • Redirect status: 301 is cached by browsers, so repeat visits never reach your server and click counts undercount. Use 302 or 307.
      • Reserved codes: any code that matches one of your own paths (docs, links, health) must be rejected at validation.
      • Expiry: compare expires_at with datetime.now(timezone.utc). Both sides must be timezone-aware.
      • Rate limiting: a fixed window is one Redis counter per client per minute. INCR a key like rl:{client}:{minute}, set a 60-second EXPIRE when the count is 1, and return 429 above your limit. Two traps: INCR and EXPIRE are separate calls, so run them in a pipeline with transaction=True; and behind a proxy, request.client.host is the proxy's address (and request.client can be None), so configure the server to trust the proxy's forwarded header (uvicorn: --forwarded-allow-ips).
      • Counting clicks at scale: writing to Postgres on every redirect gets expensive. Stretch goal: INCR in Redis and flush totals to the database periodically.
      • Normalize before storing: str(payload.url) from HttpUrl gives a normalized URL string; decide whether identical URLs should share one code.
